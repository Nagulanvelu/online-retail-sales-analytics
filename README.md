# 📊 Online Retail Sales Analytics Dashboard

A portfolio-ready Data Analytics project using **Python, Pandas, MySQL, SQL, and Power BI** to analyze online retail sales and generate actionable business insights.

---

## 🎯 Objective

Analyze online retail transactions to understand:

- 💰 Total revenue and order performance
- 📈 Monthly sales trends
- 🛍️ Top-performing products
- 🌍 Revenue contribution by country
- 👥 Customer purchasing behavior
- 🧾 Average Order Value (AOV)

---

## 🗂️ Dataset

**Source:** UCI Machine Learning Repository — Online Retail

- **541,909** original transaction records
- Transaction period: **01/12/2010 – 09/12/2011**
- UK-based non-store online retailer
- License: **CC BY 4.0**

Dataset:

https://archive.ics.uci.edu/dataset/352/online+retail

## 📊 Data Processing

The original dataset was cleaned using Python and Pandas.

Processing included:

- Removing cancelled/invalid transactions
- Removing invalid quantity and price values
- Removing missing customer/date records
- Creating a `Revenue` column
- Creating `Year`, `Month`, `MonthName`, and `YearMonth` fields
- Preparing the cleaned dataset for MySQL analysis

### Clean Dataset

| Metric | Value |
|---|---:|
| Cleaned Records | 397,884 |
| Unique Customers | 4,338 |
| Unique Orders | 18,532 |
| Total Quantity Sold | 5,167,812 |
| Total Revenue | £8,911,407.90 |
| Average Order Value | £480.87 |

## 🚀 How to Run

### 1. Prepare the Dataset

Follow the instructions in:

```text
data/README.md
```

Download the Online Retail dataset from the UCI Machine Learning Repository.

### 2. Install Python Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run Data Preprocessing

```bash
python python/preprocess.py
```

This generates:

```text
data/online_retail_clean.csv
```

### 4. Load Data into MySQL

Create the MySQL database and import the cleaned CSV into the:

```text
online_retail
```

table.

### 5. Run SQL Analysis

Open:

```text
sql/analysis.sql
```

Execute the queries using MySQL Workbench or the MySQL command line.

### 6. Open the Power BI Dashboard

Open:

```text
Online_Retail_Sales_Analytics_Dashboard.pbix
```

The dashboard connects to the MySQL database and contains the completed sales analytics visuals.
